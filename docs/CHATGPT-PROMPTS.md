# Lunch Angels — ChatGPT image prompts (the generation workhorse)

*Rewritten 2026-05-21 with the full creative lock. Workflow: **stills = ChatGPT (GPT Pro), motion = Flow Omni Flash.** Generate each frame in ChatGPT by attaching the listed references, then feed the still into Flow Omni as a start/end frame (motion prompts live in FLOW-SHOTS.md).*

## GLOBAL RULES — apply to every prompt
- **Always say 16:9.** ChatGPT defaults to square otherwise.
- **Two layers:** the character is a clean, soft 2D cel-animation cartoon (very few lines, no texture, small simple eyes — never big anime eyes); the room/world is a loose hand-painted watercolor. Character crisper than the painted background.
- **Re-attach the character's locked sheet every time** they appear — don't let ChatGPT draw them from memory. If the painting style wanders, attach a watercolor plate as a style anchor too.
- **Era grades:** Movement I (night market) = cold lavender-blue winter NIGHT, warm pooled glow. Flashback #7 = warm SEPIA 1980s. Movement II (modern cafeteria) = bright, cool-clean PRESENT-DAY daylight.
- **Tray colors:** TEAL = 1980s (#7). WHITE/cream = present day (#20, #21).
- **The giver's hand is ALWAYS off-frame** in #7 and #20 — the hand is the audience; never show a person placing the tray.
- **Wardrobe (recognition engine):** The Man = olive hoodie + blue backpack (open dark coat may layer for the cold, keep the pack visible). The Boy = olive crewneck sweater + the same blue backpack. Mateo = red/rust hoodie + green backpack + curly hair (his own kid). Doug = navy fur-collar parka at the night market.
- **Giving Machines:** brand-accurate, ~15% corner anchor, never centered. Overlay the real wordmark in post for readable text.

## THE TWO BIG CRAFT RULES (new — read before the cafeteria shots)
- **CROWDED, NOT EMPTY (present day).** Mateo's loneliness is being *unseen in a full room*, not alone in an empty one. Put him in a busy cafeteria where every other kid has a tray — he is the ONLY one sharp and in focus; everyone else is soft, semi-silhouette, slightly out of focus. Life happening around an island of stillness. *We* see him; his world doesn't.
- **SAME SCHOOL, TWO ERAS (felt, never named).** The 1980s room and the modern room are the same school, remodeled. Keep the permanent **bones** in every cafeteria shot: windows on the LEFT wall, serving line on the BACK wall, a utensil caddy in the FRONT-LEFT corner. **Match-frame #7 (Boy) and #17 (Mateo):** same camera, same table position, same angle — so the room morphs around an unchanged hungry kid. The flashback empties the room (memory); the present fills it (indifference). Same shot, opposite fullness.
