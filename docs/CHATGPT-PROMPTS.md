# Lunch Angels — ChatGPT image prompts (the generation workhorse)

*Created 2026-05-21. Workflow locked: **stills = ChatGPT (GPT Pro), motion = Flow Omni Flash.** Generate each frame in ChatGPT by attaching the listed references, then feed the still into Flow Omni as a start/end frame (motion prompts live in FLOW-SHOTS.md).*

## GLOBAL RULES — apply to every prompt below
- **Always say 16:9.** ChatGPT defaults to square otherwise.
- **Two layers:** the character is a clean, soft 2D cel-animation cartoon (very few lines, no texture, small simple eyes — never big anime eyes); the room/world is a loose hand-painted watercolor. Character crisper than the painted background.
- **Re-attach the character's locked sheet every time he/she appears** — don't let ChatGPT draw them from memory. If the painting style wanders, also attach a watercolor plate as a style anchor.
- **Era grades:** Movement I (night market) = cold lavender-blue winter NIGHT with warm pooled glow. Flashback #7 = warm SEPIA 1980s. Movement II (modern cafeteria) = bright, cool-clean PRESENT-DAY daylight (not sepia).
- **Tray colors:** TEAL = 1980s (#7). WHITE/cream = present day (#20, #21).
- **The giver's hand is ALWAYS off-frame** in #7 and #20 — the hand is the audience; never show a person placing the tray.
- **Wardrobe (recognition engine):** The Man = olive hoodie + blue backpack (an open dark coat may layer over for the cold, keep the pack visible). The Boy = olive crewneck sweater + the same blue backpack. Mateo = red/rust hoodie + green backpack + curly hair (his own kid). Doug = navy fur-collar parka at the night market.
- **Giving Machines:** brand-accurate, ~15% corner anchor, never centered. Overlay the real wordmark in post for any readable text.
- No gimmick camera language here (that's the motion pass).
